# VuloChat for Android (`Android/`)

Capacitor wrapper around the VuloChat website. The phone app shows the same site, laid out for small screens: slide-out drawer for servers and channels, and the hardware back button closes panels before it leaves the app.

## Layout

```
Android/
├── capacitor.config.json          app id, web directory, plugin settings
├── package.json                   Capacitor dependencies
├── scripts/prepare-android.mjs    generates android/ and patches the manifest and Gradle
├── www/                           website build (copied in by CI or by hand)
└── android/                       native Gradle project (generated, not committed)
```

`android/` is generated by Capacitor the first time you run the prepare script. It is ignored by git on purpose, so the generated Gradle wrapper and manifest always match the installed Capacitor version.

## Building an APK

```bash
# 1. Build the website and copy it in
#    (from the repository root)
npm install && npm run build
rm -rf Android/www && cp -r dist Android/www

# 2. Native project
cd Android
npm install
node scripts/prepare-android.mjs

# 3a. Debug APK (no signing needed)
cd android && ./gradlew assembleDebug

# 3b. Signed release APK
export VULO_KEYSTORE_PATH=/path/to/vulochat.jks
export VULO_KEYSTORE_PASSWORD=...
export VULO_KEY_ALIAS=vulochat
export VULO_KEY_PASSWORD=...
./gradlew assembleRelease
```

Requires JDK 17 and the Android SDK (Android Studio installs both).

To create a keystore once: `keytool -genkeypair -v -keystore vulochat.jks -alias vulochat -keyalg RSA -keysize 2048 -validity 10000`. Keep the file and passwords somewhere safe. Losing them means you cannot publish updates under the same app id.

## What the native shell handles

- **Hardware back button**: closes an open drawer or dialog first, then goes back to Home, then minimises the app (see `src/components/AppShell.tsx`).
- **Status bar**: dark style that matches the app.
- **Keyboard**: `adjustResize` so the message box stays visible when the keyboard opens.
- **Permissions**: internet, microphone (voice channels), audio settings and notifications.

## Not yet wired up

- **Push notifications** need a Firebase project. Add `google-services.json` to `android/app/` and call `PushNotifications.register()` from the web layer. The plugin is installed and configured, but no token is requested yet.
